# Rosetta Tone Lab

Prototype for reading and translating hair colour codes across brands (Wella, L'Oréal, TIGI, Matrix, Redken), with a tone wheel, chip grid, depth ladder, brand pages, a Wella mixing and corrective guide, and NVQ Level 2 practice questions.

- `site/index.html` – the app (single page, no build step)
- `site/data/rosetta.json` – brand, line and shade data
- `site/data/wella-guide.json` – Wella mixing, developer and corrective data (transcribed from the Wella Color Expert workbook 2026)
- `site/wheel-lab.html` – the wheel layout lab
- `netlify.toml` – Netlify settings: publish `site/`, no build command

Hosted on Netlify from this repo. Saved profiles and training scores are kept in each browser for now; shared accounts and progress are a later step.

Private trial only: brand charts and course material belong to their publishers.
